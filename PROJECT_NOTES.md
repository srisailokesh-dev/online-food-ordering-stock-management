# Project Notes

## What is included

This repository contains the full source package supplied for the Online Food Ordering project, including:

- Customer-facing PHP pages
- Admin panel
- CSS/SCSS
- JavaScript libraries and application scripts
- Images and fonts
- Database SQL dump
- Existing project license

## Public-repository preparation

The supplied SQL dump contained seeded account/order/remark records. Those records have been removed from the public copy to avoid publishing unnecessary user/contact information and account credentials.

The application source itself still reflects the original academic implementation. Review and modernization are recommended before production use.

## Portfolio positioning

For a Data Science portfolio, this project is best presented as a **software/database project that can be extended into a data-driven system**, rather than claiming that machine-learning functionality is already implemented.
